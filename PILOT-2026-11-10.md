## Defect yang ditemukan pilot dan sudah diperbaiki

1. Health check membandingkan `build_id` dengan nama folder → gagal saat paket
   di-rename. Diperbaiki memakai `build.json`.
2. Evidence ID hilang setelah reset → arsip/restore + event `lab.reset`.
3. Q9 KampusMart tidak dapat ditemukan dari dokumen peserta → `/legacy/info`,
   dokumen publik lengkap.
4. Evidence terlalu membocorkan (`cross_owner`, `private_rows`) → dihapus.
5. Q10 PerpusDigital tidak punya UI petugas → `/staff/books`.
6. Field metadata asing diterima diam-diam → sekarang 400.
7. EventPass tidak punya UI edit tiket; definisi DOM kabur → form nama tampilan,
   definisi operasional, invariant check-in.
8. `note` SOC membocorkan ground truth → netral.
9. Device/geo SOC-1 menandai novelty → diganti wajar; baseline korban ditambah.
10. SOC-2 event benign di dalam sequence jahat → dikeluarkan; ditambah Office benign.
11. SOC-3 `flow_id` alert kedua salah → diperbaiki.
12. Format aturan tidak terdokumentasi di SOC-2/3 → ditambahkan.
13. Path dokumen SOC salah (`data/train` vs `train`) → diperbaiki.
14. `freeze` menulis ke `instructor-private` di paket siswa → `freeze.json` root.

## Keputusan dan verifikasi lain

- **Sigma:** `soc-labs/docs/SIGMA-MAPPING.md` memetakan field, contoh YAML per
  kasus, dan batas korelasi temporal.
- **DEV-2 signing:** RSA-2048 lokal, signature detached atas attestation
  kanonik, fingerprint key di trust policy. Verifikasi 20/20 (tampered,
  wrong-source, stale, untrusted-builder, missing-builder, unsigned,
  bad-signature, untrusted-key, golden).
- **DFIR artefak biner:** memo `dfir-cases/docs/DFIR-ARTIFACT-DECISION.md` +
  prototipe PCAP 330 byte/3 frame dan SQLite 6 baris; verifikasi tanpa tool
  eksternal. Rekomendasi: teks-only untuk rilis, add-on opsional, EVTX belum.
- **GRC hukum:** PP 71/2019 terverifikasi **Berlaku** di
  `peraturan.go.id/id/pp-no-71-tahun-2019` (10 Nov 2026), tanpa relasi
  pencabutan. Instrumen pembentukan Lembaga PDP tidak ditemukan pada pencarian
  resmi; tetap ditandai perlu verifikasi.
