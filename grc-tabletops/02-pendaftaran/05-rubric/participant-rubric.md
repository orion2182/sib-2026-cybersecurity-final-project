# Rubrik Publik — GRC-2 Pendaftaran dan Pembayaran Kampus

**Total:** 100 poin
**Dipakai untuk:** paket tertulis (18 Des) dan presentasi (21–23 Des)
**Catatan:** hanya dimensi dan deskriptor. Tidak ada jawaban model.

---

## 1. Bobot

| Komponen | Poin |
| --- | ---: |
| A. Inventaris, stakeholder, keterlacakan asumsi | 15 |
| B. Analisis dan prioritas risiko | 20 |
| C. Peta data dan analisis privasi dengan sumber resmi | 20 |
| D. BIA, RTO/RPO, strategi kelangsungan | 20 |
| E. Keputusan inject, komunikasi pimpinan, rencana aksi | 15 |
| F. Tanya jawab kontribusi individu | 10 |

## 2. Deskriptor

### A. Inventaris dan stakeholder (15)

| Level | Deskriptor |
| --- | --- |
| 0 | Tidak ada daftar aset/ stakeholder |
| 1 | Daftar ada, tanpa pemilik dan tanpa label asumsi |
| 2 | Aset dan stakeholder lengkap; sebagian besar klaim berlabel |
| 3 | Setiap aset punya pemilik; ada pihak yang terdampak tetapi tidak punya suara (mahasiswa, pendaftar, relawan) |
| 4 | Seperti level 3, ditambah analisis bagaimana ketiadaan suara itu mengubah keputusan |

### B. Analisis dan prioritas risiko (20)

| Level | Deskriptor |
| --- | --- |
| 0 | Daftar kontrol, bukan risiko |
| 1 | Skor tanpa bukti; risiko tidak dapat diuji |
| 2 | Pernyataan sebab–akibat; skor konsisten; tiga prioritas |
| 3 | Prioritas mempertimbangkan tenggat akademik; ada risiko data manual dan risiko vendor |
| 4 | Seperti level 3, ditambah trade-off: menutup satu risiko memperbesar risiko lain |

### C. Peta data dan privasi (20)

| Level | Deskriptor |
| --- | --- |
| 0 | Tanpa peta data; tanpa rujukan hukum |
| 1 | Peta sebagian; rujukan tanpa nomor atau salah |
| 2 | Aliran dan peran tergambar; rujukan benar |
| 3 | Saluran tidak resmi dipetakan; minimisasi dianalisis; dasar pemrosesan dinilai |
| 4 | Seperti level 3, ditambah aturan data untuk proses darurat yang dapat dijalankan |

> Rujukan pasal yang salah mengurangi nilai komponen ini.

### D. BIA, RTO/RPO, kelangsungan (20)

| Level | Deskriptor |
| --- | --- |
| 0 | Tidak ada BIA atau hanya daftar sistem |
| 1 | Dampak tanpa angka; RTO/RPO seragam |
| 2 | Dampak 4 jam/ 1 hari/ 3 hari terisi; target berbeda antar layanan |
| 3 | Perhitungan dapat diperiksa; ada WRT; ada kesenjangan yang diakui |
| 4 | Seperti level 3, ditambah biaya alternatif dan rencana uji dengan kriteria lulus |

### E. Keputusan inject dan komunikasi (15)

| Level | Deskriptor |
| --- | --- |
| 0 | Tidak ada memo |
| 1 | Memo tidak menyebut perubahan |
| 2 | Keputusan jelas, ada pemilik dan risiko sisa |
| 3 | Perubahan dilacak ke fakta; ada alternatif ditolak; komunikasi sesuai audiens |
| 4 | Seperti level 3, ditambah kesadaran bahwa sebagian keputusan bergantung pada informasi yang belum ada |

### F. Tanya jawab individu (10)

| Level | Deskriptor |
| --- | --- |
| 0 | Tidak dapat menjelaskan bagiannya |
| 1 | Menjelaskan isi, bukan alasan |
| 2 | Menjelaskan alasan dan bukti |
| 3 | Menjelaskan trade-off dan batas keyakinan |
| 4 | Menjelaskan apa yang berubah jika satu fakta kunci salah |

## 3. Penalti

| Pelanggaran | Pengurangan |
| --- | ---: |
| Mengarang nomor pasal/ kutipan | hingga −10 pada komponen C |
| Data pribadi nyata | −10 dan paket dikembalikan |
| Deliverable tidak lengkap | −5 per berkas |
| Tidak ada pemilik/ tenggat | −2 per kejadian, maks. −6 |
| Menyalin pekerjaan kelompok lain | sesuai kebijakan akademik |

## 4. Yang tidak dinilai

- Panjang dokumen.
- Jumlah framework.
- Jumlah kontrol.
- Desain slide.
- Kesamaan dengan kelompok lain.

## 5. Pertanyaan presentasi

1. Apa risiko terbesar yang Anda terima, dan siapa yang menandatanganinya?
2. Bagaimana Anda memastikan mahasiswa yang sudah membayar tidak dirugikan?
3. Di mana perhitungan Anda paling rapuh?
4. Jika pemulihan tersedia besok, apa yang berubah?
