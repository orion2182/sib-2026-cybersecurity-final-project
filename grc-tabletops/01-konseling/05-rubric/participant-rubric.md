# Rubrik Publik — GRC-1 Layanan Konseling Mahasiswa

**Total:** 100 poin
**Dipakai untuk:** penilaian paket tertulis (18 Des) dan presentasi (21–23 Des)
**Catatan:** rubrik ini hanya memuat **dimensi dan deskriptor**. Tidak ada jawaban model di sini.

---

## 1. Bobot

| Komponen | Poin |
| --- | ---: |
| A. Inventaris, stakeholder, keterlacakan asumsi | 15 |
| B. Analisis dan prioritas risiko | 20 |
| C. Peta data dan analisis privasi dengan sumber resmi | 20 |
| D. BIA, RTO/RPO, strategi kelangsungan | 20 |
| E. Keputusan inject, komunikasi pimpinan, rencana aksi | 15 |
| F. Tanya jawab kontribusi individu | 10 |

## 2. Deskriptor per komponen

Skala tiap komponen: **0 = tidak ada, 1 = lemah, 2 = cukup, 3 = kuat, 4 = sangat kuat** (dikalikan bobot komponen).

### A. Inventaris, stakeholder, keterlacakan asumsi (15)

| Level | Deskriptor |
| --- | --- |
| 0 | Tidak ada daftar aset/stakeholder, atau seluruhnya generik |
| 1 | Ada daftar, tetapi tanpa pemilik dan tanpa pemisahan fakta/asumsi |
| 2 | Aset dan stakeholder lengkap; sebagian besar klaim berlabel |
| 3 | Setiap aset punya pemilik; asumsi berlabel dan diuji; ada pihak yang sering terlewat (mis. mahasiswa, klinik mitra) |
| 4 | Seperti level 3, ditambah penjelasan mengapa pihak tertentu tidak punya suara dan bagaimana hal itu memengaruhi keputusan |

### B. Analisis dan prioritas risiko (20)

| Level | Deskriptor |
| --- | --- |
| 0 | Daftar risiko tanpa skor atau tanpa bukti |
| 1 | Skor ada, tetapi tidak konsisten; risiko ditulis sebagai "kontrol tidak ada" |
| 2 | Pernyataan risiko sebab–akibat; skor konsisten; 3 prioritas |
| 3 | Prioritas dapat dipertahankan; ada risiko keselamatan dan vendor; kontrol saat ini dinilai dengan bukti |
| 4 | Seperti level 3, ditambah analisis trade-off antarrisiko (menutup satu risiko membuka risiko lain) |

### C. Peta data dan analisis privasi dengan sumber resmi (20)

| Level | Deskriptor |
| --- | --- |
| 0 | Tidak ada peta data; tidak ada rujukan hukum |
| 1 | Peta data sebagian; rujukan hukum disebut tanpa nomor atau salah |
| 2 | Aliran dan peran tergambar; rujukan resmi dengan nomor yang benar |
| 3 | Peran pengendali/prosesor/subprosesor tepat; transfer lintas negara dianalisis; kutipan sesuai konteks |
| 4 | Seperti level 3, ditambah identifikasi ketentuan yang **tidak** berlaku atau perlu verifikasi, dan alasan mengapa |

> Rujukan yang salah nomor akan mengurangi nilai komponen ini, meskipun analisisnya masuk akal.

### D. BIA, RTO/RPO, strategi kelangsungan (20)

| Level | Deskriptor |
| --- | --- |
| 0 | Tidak ada BIA atau hanya daftar sistem |
| 1 | BIA ada, tetapi tanpa angka dampak; RTO/RPO seragam untuk semua layanan |
| 2 | Dampak 4 jam/1 hari/3 hari diisi; RTO/RPO berbeda antar layanan |
| 3 | RTO/RPO terkait bukti kemampuan; ada kesenjangan yang diakui; ada prosedur manual |
| 4 | Seperti level 3, ditambah rencana uji dengan kriteria lulus dan perhitungan biaya alternatif |

### E. Keputusan inject, komunikasi pimpinan, rencana aksi (15)

| Level | Deskriptor |
| --- | --- |
| 0 | Tidak ada memo inject |
| 1 | Memo ada, tetapi tidak menyebut apa yang berubah |
| 2 | Keputusan jelas; ada pemilik; ada risiko sisa |
| 3 | Perubahan keputusan dilacak ke fakta inject; ada alternatif yang ditolak; komunikasi sesuai audiens |
| 4 | Seperti level 3, ditambah kesadaran bahwa sebagian keputusan bergantung pada informasi yang belum ada, dengan rencana konfirmasi |

### F. Tanya jawab kontribusi individu (10)

| Level | Deskriptor |
| --- | --- |
| 0 | Tidak dapat menjelaskan bagian yang dikerjakan |
| 1 | Menjelaskan isi dokumen, tetapi tidak alasannya |
| 2 | Menjelaskan alasan dan bukti |
| 3 | Menjelaskan trade-off dan batas keyakinan |
| 4 | Menjelaskan apa yang akan diubah jika satu fakta kunci ternyata salah |

## 3. Penalti

| Pelanggaran | Pengurangan |
| --- | ---: |
| Mengarang nomor pasal atau mengutip tanpa verifikasi | hingga −10 pada komponen C |
| Menggunakan data pribadi nyata | −10 dan paket dikembalikan |
| Tidak menyerahkan salah satu dari 9 deliverables | −5 per berkas |
| Deliverable tidak dapat dijalankan (tanpa pemilik/ tanggal) | −2 per kejadian, maks. −6 |
| Menyalin pekerjaan kelompok lain | proses akademik sesuai kebijakan kampus |

## 4. Yang **tidak** dinilai

- Panjang dokumen.
- Jumlah framework yang disebut.
- Jumlah kontrol yang didaftar.
- Keindahan desain slide.
- Kesamaan dengan kelompok lain (kasus sengaja berbeda).

## 5. Pertanyaan yang dinilai saat presentasi

1. Apa risiko terbesar yang Anda **terima**, dan siapa yang menandatanganinya?
2. Fakta apa yang paling mengubah keputusan Anda?
3. Di mana analisis Anda paling lemah, dan bagaimana Anda mengetahuinya?
4. Jika anggaran dipotong 50%, apa yang Anda pertahankan lebih dulu?
