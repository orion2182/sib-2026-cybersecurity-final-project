# Final Project Cyber Security SIB 2026

Repository perencanaan privat untuk final project **65 mahasiswa dalam 13 kelompok**. Pembagian tema: VAPT 3, DFIR 3, SOC 3, GRC/privasi/BCP 2, dan DevSecOps/supply chain 2. Kalender proyek berlangsung **20 November–23 Desember 2026**.

## Dokumen perencanaan

| Tema | Dokumen utama |
| --- | --- |
| VAPT | `Riset-Rancangan-VAPT-KampusMart-2026.md`, `Arsitektur-Lab-VAPT-KampusMart-Lokal.md`, tiga kartu target, rancangan mahasiswa, dan formulir otorisasi PTES |
| DFIR | `Riset-Lab-DFIR-2026.md` |
| SOC | `Riset-Lab-SOC-2026.md` |
| GRC, privasi, BCP | `Riset-Lab-GRC-Privasi-BCP-2026.md` |
| DevSecOps, supply chain | `Riset-Lab-DevSecOps-Supply-Chain-2026.md` |

`Rencana-Proyek-Akhir-Cybersecurity-KampusMart.pdf` adalah draft rujukan awal. `outputs/` menyimpan salinan XLSX timeline dan checklist mentor. [Google Sheet mentor](https://docs.google.com/spreadsheets/d/1AmBhy5wWf-PDKO3RWuc2AvEtrVgvnmWE_nGKKzPhJ_E/edit) adalah versi kerja bersama; salinan XLSX di repo ini adalah snapshot.
